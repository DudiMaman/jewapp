# נשמה · Neshama

A daily Jewish-life companion for **prayer, Tehillim (Psalms), and mitzvot** — with an AI
guide and gentle, Shabbat-aware reminders. Subscription mobile app for **iOS + Android**,
Hebrew-first (RTL).

## Documentation

- **[Product Specification (`docs/SPEC.md`)](docs/SPEC.md)** — full app specification:
  information architecture, onboarding funnel, core features, notifications, personalization,
  monetization, data model, and a screen-by-screen reference.
- **Design system** — a blue-and-white palette with delicate gold accents, delivered as a
  Claude Design system (see §12 of the spec).

## At a glance

- **5 tabs:** צ'אט (Chat) · סידור (Siddur) · היום (Today) · תהילים (Tehillim) · תנ"ך (Tanakh)
- **Personalized** by nusach, gender, age, Hebrew name, and Hebrew reading level
- **AI companion** that explains any prayer/verse and recommends the right chapter
- **Daily journey** with streaks that respect Shabbat, and time-aware push reminders
- **Subscription:** 7-day free trial · ₪17.90/week · ₪149.90/year
